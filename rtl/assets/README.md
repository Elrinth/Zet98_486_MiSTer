# FPGA data files

- `boot-font.mem`: 8x8 font (128 characters, one byte per row) used by the
  boot-help text and the "LOADING D0..." / "LOADING D1..." floppy caption.
- `boot-text.mem`: boot-help screen text.
- `audio-decimator-coeffs.mem`: 255-tap anti-alias FIR for
  `rtl/audio_decimator.sv`, generated by `scripts/design_audio_decimator.py`.

- `overlay-icons.mem`: the later, self-drawn floppy/CD/HDD icons generated by
  `scripts/make_overlay_icons.py`. These replace the older unlicensed artwork.
- `activity.mem`: compact font/icon ROM generated by `scripts/make_activity_rom.py`.
  It stores the 17 caption glyphs and four frames per device in 1,024 bytes
  (one M10K), using the existing font and every second self-drawn icon frame.
  Run the generator with `--check` to verify the committed data.
