# FPGA data files

- `boot-font.mem`: 8x8 font (128 characters, one byte per row) used by the
  boot-help text and the "LOADING D0..." / "LOADING D1..." floppy caption.
- `boot-text.mem`: boot-help screen text.
- `audio-decimator-coeffs.mem`: 255-tap anti-alias FIR for
  `rtl/audio_decimator.sv`, generated by `scripts/design_audio_decimator.py`.

The animated floppy-disk icon was removed (area savings, and its artwork had
no identified license); only the text caption remains.
