PC-98 HDI 256 → 512 converter

Old PC-98 hard-disk images (10/20/40 MB SASI disks) use 256-byte sectors, which the Zet98 486 MiSTer core cannot boot. Drop an .hdi here to get a 512-byte-sector copy named …-512b.hdi.

Everything runs in your browser; the image is not uploaded anywhere.

    Same conversion as scripts/pc98_hdi_256to512.py (Python, for the command line). GPL-3.0-or-later.
